No verification or validation case has been run for this revision. No requirement is claimed as verified, and no customer requirement as validated.

The model holds the plan: cases, methods, subjects and the requirements each case covers. It does not hold results. When cases are run, their results are to be recorded against the case and the configuration under test, and reported in a verification report, which is not part of this revision.
